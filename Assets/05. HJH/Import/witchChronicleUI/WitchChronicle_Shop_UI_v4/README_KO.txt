권장 사용 방식
- ItemSlot은 BG와 Frame을 별도 Image로 겹쳐 사용합니다.
- ListRow, DetailPanel, Quantity 버튼은 Image Type을 Sliced로 사용할 수 있습니다.
- SelectedBar는 탭 하위에 별도 Image로 두고 선택 상태에서만 활성화합니다.
- 상품 목록 슬롯과 서브 카테고리 슬롯은 BG와 Frame을 분리했습니다.
- 일반 상태에서는 Normal BG + Normal Frame을 사용합니다.
- 선택 상태에서는 Selected BG + Selected Frame으로 교체합니다.
- Shop_SelectedMarker_Right는 선택 상품 슬롯의 우측에 별도 Image로 배치합니다.
- 메인 카테고리는 Frame과 Icon을 별도 Image로 조립하거나, 카테고리별 완성형 Normal/Selected PNG를 바로 사용할 수 있습니다.
- Hover 상태는 Shop_MainCategory_Frame_Hover를 아이콘 하위 프레임으로 교체해서 사용합니다.
- 상단 서브 카테고리의 선택 표시는 Shop_Subcategory_SelectedBar_Short를 사용합니다.
- 모든 텍스트와 아이콘은 TextMeshPro/Image로 별도 배치합니다.
